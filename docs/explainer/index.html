A pilot flies the city. A filter keeps a way out.

Every 20 ms the gate test-flies escapes from where the pilot's input leads. The pilot keeps control while one of them gets away clean.

The problem

JSBSim's Cessna 172, reproduced bit for bit, in a procedural city. Anyone can fly it, and fly it into a building.

What the filter must guarantee

From one allowed start, hostile and kamikaze pilots: with the filter, nothing is touched.

How the gate decides, every 20 ms

After the pilot's next input, it test-flies its escapes in order. The first that gets away clean is kept and the pilot flies on; if none does, it flies the last one that passed.

Why it can't crash, and the one open condition

In Lean: the statement, and its two conditions

No reachable state is a crash:

def Safe (M : CityMap) (F : Filter) : Prop :=
  ∀ p, Reach F p → ¬ Crash M p.1

The open condition: whenever the end-of-escape test passes on the gate's own rollout, flying on never crashes:

def TermSoundR : Prop :=
  ∀ x, Origin G Init x → ∀ n, G.term (G.flyN n x) = true → SafeForever G Crash (G.flyN n x)

The headline theorem:

theorem cityGate_spec_safe_of_tb (hT : TermSoundR cityGate (CrashH 7) GInit) (hTb : TbBounded) :
    CitySafety.Safe cityMap specFilter

ConditionalLean-checked, conditional on TermSoundR (not yet true for today's end test) and TbBounded.
